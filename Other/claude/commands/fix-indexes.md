You are repairing SIMA indexes.

1. SCAN ALL INDEXES:
   - Master index
   - Domain indexes
   - Type indexes (LESS, DEC, BUG, etc.)

2. DETECT ISSUES:
   - Missing entries
   - Orphaned entries
   - Broken links
   - Inconsistent formatting

3. REPAIR INDEXES:
   - Add missing entries to indexes
   - Remove invalid entries
   - Fix broken links
   - Standardize formatting

4. VALIDATE:
   - Verify all entries indexed
   - Verify all index entries valid
   - Check cross-references

5. UPDATE:
   - Save repaired indexes
   - Update related routers

Report repairs made.
